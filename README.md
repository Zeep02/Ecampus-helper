## 접속 링크

# [❗❗❗사이트 링크❗❗❗](http://1.248.25.185:5000/)

## 주요 기능

- 이캠퍼스 오늘의 할일 기능 복원
- 이거 왜 없앤거야 꼴받게

- 아이디와 비밀번호를 정확하게 입력하셔야 합니다.
